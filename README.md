# Doddie Prawarjito portfolio

[Visit the portfolio](https://mrrobotdude.github.io/).

Selected work in business applications, SQL performance, system integration, interface design and machine learning. English and Bahasa Indonesia, accessible project dialogs, feature galleries, and downloadable PDF resumes.

Five business and engineering projects lead the site. FisHE, Go Truck and Voila have a separate design section. InSOgram and Low-light Vision show interactive frontend work and computer-vision results. Ten project galleries contain 39 screenshots and result figures.

The resume buttons download the BRI software-engineer ATS PDF in the selected language. The Word and PDF versions contain a clickable portfolio link.

## Run and deploy

Run `npm run check`, then serve `site/` with a static HTTP server. GitHub Actions validates the site and deploys `site/` to GitHub Pages.

InSOgram's standalone React source is in `demo-source/insogram/`; its compiled browser demo is in `site/demos/insogram/`. It stores changes on the current device. Shared accounts and message delivery are outside the frontend release.

The company presentation is hosted separately in [ats-company-website](https://github.com/MrRobotdude/ats-company-website). This portfolio contains its project gallery and contribution summary.

Public project scope and attribution are described in each case study. Screenshots use synthetic demonstration records or publicly visible company pages. No employer backend, private client records or credentials are included.
