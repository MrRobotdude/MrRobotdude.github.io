# InSOgram interactive frontend

A React photo-sharing demo with posting, video/image preview, comments, likes, saves, creator discovery, follows, profile editing and stories. Changes are stored on the current device. Messages are a local composition preview; no delivery or shared account system is claimed.

Run with Node 22 or 24: `npm ci`, `npm start`. Build: `npm run build`. Interaction tests: `npm test -- --watchAll=false --runInBand src/demo/store.test.js`.

This standalone release contains the reviewed frontend and custom sample illustrations. The frontend source uses React, React Router and Create React App; their licences remain applicable. Logo and interface authored for InSOgram; new interaction implementation and illustrations added in 2026.
