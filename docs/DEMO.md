# ATS Company Website: demonstration guide

## Story to tell

A public catalogue for a company whose products and services benefit from clear navigation and visual explanation.

## Walkthrough

Browse home, products, services, projects, and contact on desktop and mobile widths.

Explain one technical choice: Reusable cards, carousels, product/service constants, hash routes, and lazy-loaded pages organize the catalogue. The interface retains its licensed Now UI Kit foundation.
